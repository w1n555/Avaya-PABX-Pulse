Avaya PABX Pulse — easy install (ZIP → IIS → Login)
===================================================

Your goal (supported):
  1. Install IIS yourself (Windows Features)
  2. Extract this package to ANY folder you choose
     (example only: C:\inetpub\wwwroot\CM — any path is fine)
  3. Right-click PowerShell → Run as administrator. Then:

       cd <YOUR_EXTRACT_FOLDER>\scripts
       install.bat

     (install.bat bypasses Windows script policy. Same as:
       powershell -ExecutionPolicy Bypass -File .\install.ps1 )

  4. Confirm ROOT path when asked (default = package folder)
  5. Open the URL printed (typical nested install):
       http://127.0.0.1:8888/CM/
       API: http://127.0.0.1:8888/CM/api/health
     (site root http://127.0.0.1:8888/ can stay YOUR other web service)
  6. Enter YOUR CM Host + Password → Login → monitoring starts

What install.ps1 does:
  - Detects IIS (if missing, tells you to install IIS first — does NOT auto-install IIS)
  - Checks / installs .NET 8 Hosting Bundle if missing (winget or download)
  - Checks / installs Python 3.12 if missing (winget or python.org, with PATH)
  - Asks LOCAL ROOT path (e.g. ...\wwwroot\CM) — your app files only
  - Asks existing IIS PORT (where your main web service already runs)
  - Default Nested (parasite) mode — for ALL machines:
      * Finds the IIS site on that port
      * Adds ONLY:
          /CM     -> your ROOT path
          /CM/api -> your ROOT\api
      * NEVER changes parent site ROOT physical path
      * NEVER replaces http://host:port/ homepage
  - Creates Python venv + installs bundled avaya-ossi (vendor\)
  - Registers OSSI bridge auto-start at Windows logon

  Optional: -IisMode Dedicated -SitePort 8890  (full site on a FREE port only)

Python (offline / no CDN):
  GitHub Release asset python-runtime.zip
  Extract so you have:  <ROOT>\python\runtime\python.exe
  Then install.bat will NOT ask to install Python 3.12.

You do NOT need a separate OSSI repo clone.
You do NOT need to start the bridge manually every day.

Requirements:
  - Windows IIS (user installs)
  - Admin rights for install.ps1
  - Internet access the first time (to download Hosting Bundle / Python if missing)

Optional flags:
  -SkipDotNetInstall   do not auto-install Hosting Bundle
  -SkipPythonInstall   do not auto-install Python
  -SkipUpdate          do not git pull (freeze code on disk)
  -NonInteractive -RootPath "C:\path" -SitePort 8888

------------------------------------------------------------
ONE command for new install AND upgrade (auto-detect)
------------------------------------------------------------
Always the same:

  cd <YOUR_EXTRACT_FOLDER>\scripts
  install.bat

Script detects:
  - git clone?  -> auto git pull from GitHub
  - existing api/venv/data?  -> full upgrade path
  - keeps data_live\monitored_trunks.json
  - republish api, rewire IIS, restart bridge

No need for -Update flag.

ZIP-only (no .git): re-run install.ps1 after replacing files,
or convert to git clone once for auto pull next time.
