Avaya PABX Pulse — install (manual prereqs → offline wheels → IIS)
==================================================================

Production servers often have NO CDN. Do not expect winget / auto-download
of the Hosting Bundle or Python. Install those yourself, then run install.bat.

----------------------------------------------------------------
Step 0 — Manual prerequisites (you install)
----------------------------------------------------------------
  1. Windows IIS (Windows Features → Internet Information Services)
     Include: IIS Management Console, World Wide Web Services
  2. .NET 8 Hosting Bundle (NOT the SDK)
     https://dotnet.microsoft.com/download/dotnet/8.0
  3. Python 3.11 or 3.12 only (prefer 3.12)
     https://www.python.org — tick "Add python.exe to PATH"
     Python 3.13+ is REJECTED: python\wheels are cp311/cp312 ABI only.

----------------------------------------------------------------
Step 1 — Extract package
----------------------------------------------------------------
  Preferred: download Avaya-PABX-Pulse-vX.Y.Z.zip from GitHub Releases
  (deploy tree), not only the auto "Source code" zip.
  Extract / clone to ANY folder (example only: C:\inetpub\wwwroot\CM).

----------------------------------------------------------------
Step 2 — Run installer as Administrator
----------------------------------------------------------------
  Right-click PowerShell or CMD → Run as administrator:

    cd <YOUR_EXTRACT_FOLDER>\scripts
    install.bat

  install.bat prechecks (Admin, IIS/appcmd, ANCM, Python 3.11|3.12) with
  Traditional Chinese + English errors, then runs install.ps1
  (ExecutionPolicy Bypass). Exit non-zero on precheck failure.

  Confirm ROOT path when asked (default = package folder).
  Confirm existing IIS PORT (Nested default, often 8888).
  Nested needs an IIS site ALREADY bound to that port. If none exists,
  create a parent site first, or use: install.ps1 -IisMode Dedicated -SitePort <free>.

----------------------------------------------------------------
What install.ps1 does (and does NOT do)
----------------------------------------------------------------
  DOES:
  - Ensure IIS / ANCM / Python 3.11|3.12 already present (throw if missing)
  - Nested (default) OR Dedicated IIS mode
      Nested: find site on the chosen port; add ONLY
          /CM     -> your ROOT
          /CM/api -> your ROOT\api
        NEVER changes parent site ROOT physical path / homepage
      Dedicated: -IisMode Dedicated -SitePort <free port>
  - Create python\.venv and pip-install from python\wheels (offline, no PyPI)
  - Use / publish api\CmApi.dll
  - Write api\appsettings.json (OSSI bind 127.0.0.1)
  - Register scheduled task CM-NOC-OSSI-Bridge:
      AtStartup, SYSTEM, bind 127.0.0.1:18776 (hidden via run-hidden.vbs)
  - Start bridge now; CmApi Login can also EnsureBridgeRunningAsync

  DOES NOT:
  - Auto-install IIS
  - Auto-download / winget Hosting Bundle or Python (no CDN path)
  - Bind OSSI bridge on 0.0.0.0 (loopback only)

----------------------------------------------------------------
Offline wheels
----------------------------------------------------------------
  python\wheels\ must be present (shipped in the zip/repo).
  Installer:

    pip install --no-index --find-links=python\wheels setuptools wheel paramiko python-dotenv
    pip install --no-index --no-build-isolation --find-links=python\wheels -e vendor\avaya-ossi

  No separate OSSI repo clone. No daily manual bridge start.

----------------------------------------------------------------
Security defaults
----------------------------------------------------------------
  - Bridge: 127.0.0.1:18776 (loopback only; no API key)
  - CmApi BaseUrl: http://127.0.0.1:18776
  - Restrict / firewall IIS exposure (operators)
  - web.config hides: src, scripts, python, data_live, cdr-link, avaya-ossi, docs, .git
  - Do not commit data_live\

----------------------------------------------------------------
Optional flags
----------------------------------------------------------------
  -SkipUpdate          do not git pull (freeze code on disk)
  -NonInteractive -RootPath "C:\path" -SitePort 8888
  -IisMode Dedicated -SitePort 8890

----------------------------------------------------------------
ONE command for new install AND upgrade
----------------------------------------------------------------
  cd <YOUR_EXTRACT_FOLDER>\scripts
  install.bat

  Detects git clone → git pull; keeps monitored_trunks.json;
  republish api, rewire IIS, restart bridge.

ZIP-only (no .git): re-run after replacing files, or convert to git clone
once for auto pull next time.

Typical URLs (Nested on 8888):
  http://127.0.0.1:8888/CM/
  http://127.0.0.1:8888/CM/api/health
